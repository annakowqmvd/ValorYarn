# ValorYarn

ValorYarn optimizes real-time data ingestion through multi-threaded processing and auto-scaling, simplifying orchestration and scheduler integration.

ValorYarn is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ValorYarn.git`
2. `cd ValorYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ValorYarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
